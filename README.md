# 💱 React Currency Converter

A responsive currency converter web application built using **React, Vite, and Tailwind CSS**. It fetches exchange-rate data from a currency API and allows users to convert amounts between different currencies.

## 🌐 Live Demo

🔗 [Try the Currency Converter](https://effulgent-syrniki-c4ba49.netlify.app/)

## ✨ Features

- 🔄 Convert amounts between supported currencies
- 🌍 Select source and target currencies independently
- 🔁 Swap the source and target currencies
- ⚡ Fetch exchange rates from an API
- 📱 Responsive user interface
- 🎨 Styled with Tailwind CSS
- ⚛️ Built with reusable React components and a custom hook

## 🛠️ Tech Stack

- **Frontend:** React, JavaScript, HTML
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **API:** Currency exchange-rate API
- **Deployment:** Netlify
- **Version Control:** Git and GitHub

## 🚀 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/vikasthakur8815-ui/react-currency-converter.git
```

### 2. Open the project folder

```bash
cd react-currency-converter
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL shown in your terminal.

## 📦 Production Build

To create a production build, run:

```bash
npm run build
```

The generated production files will be available in the `dist` folder.
